# Report — Standalone UK Order-Level Sales Review (`salesuk.html`)

**Date:** 2026-07-27
**Purpose:** Provide a clean, order-level, non-overlapping view of UK Shopify orders after finding that the main dashboard's per-staff tabs can double-count the same order under different definitions.
**Evidence:** `evidence/salesuk/2026-07-27_standalone-order-level-page.md`
**Status:** Live, January only (DM-Ad + Meta groups)
**Reviewer:** Not recorded.

## What it is
A new page (`pages/salesuk.html`) backed by a brand-new, self-contained endpoint (`api/salesuk.js` — deliberately not sharing code with `api/sales.js`). January tab contains two group sub-tabs so far:

| Group | Matching rule | Orders (Jan) | Net Sales (Jan) |
|---|---|---|---|
| DM-Ad | utm_campaign = Shop_DM_PMax-46_AguAsset or Shop_DM_PMax-25 | 962 | £23,092.53 |
| Meta | utm_campaign in {Sales Ads, Sales Ads – Copy, Sales Ads \| Retargeting \| Add to Cart} OR source in {Facebook, Instagram, android-app://m.facebook.com/} | 342 | £6,198.41 |

Groups are checked in a fixed priority order (DM-Ad, then Meta) so the same order can never appear in both — guaranteed by code construction, not just convention.

## Why it exists
A direct order-name comparison across the main dashboard's six January UK tabs found 1,037 of 2,156 unique orders (48%) counted in more than one tab. Rather than retrofit the existing tabs (which would risk silently changing numbers people already rely on), this is a fresh page built to let orders be reviewed and assigned by hand.
