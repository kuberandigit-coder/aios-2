ⓘ How to Use This Report

What This Report Does

This report compares all active UK bundle SKUs (from eBay UK, Amazon UK, Shopify UK) against Germany's current warehouse stock to find bundle opportunities — bundles that exist in the UK but are not yet listed in Germany.

A bundle SKU is any SKU containing a + sign, e.g. CRSF100BM+SCRN70BM+PHSH1PBRYB. Each part separated by + is a component SKU.

This report does NOT calculate build quantities or recommend creating bundles. It is an opportunity identification tool only.

Filter Pills Explained

  • All Not in Germany — Shows all 13,188 UK bundles that do not exist in Germany. Default view.
  • ✓ Ready for Review — Filters to bundles where all components are in Germany stock. Start here — these 467 are actionable today.
  • Missing Components — Filters to bundles where one or more components are missing from Germany stock. Use this to identify what stock needs to be sourced first.
  • Search SKU — Type any part of a bundle SKU to find it instantly. Works across all filter states.

Table Columns Explained

  • UK Bundle SKU — The full bundle SKU as listed in UK channels, e.g. CRSF100BM+SCRN70BM.
  • # Parts — Number of component SKUs in this bundle.
  • Component List — Each component shown as a chip:
    ✓ CRSF100BM = found in Germany stock
    ✗ SCRN70YB = NOT in Germany stock
  • DE Bundle — Always ✗ No in this table (only not-in-Germany bundles are shown).
  • Found — How many components are confirmed in Germany stock out of total (e.g. 4 / 4).
  • Missing — Count of components with no Germany stock. Zero means Ready for Review.
  • Opportunity Status —
    ✓ Ready for Review = all components in DE stock, can proceed to listing
    Missing 2 component(s) = needs stock sourcing first

Recommended Workflow

  • Step 1: Click ✓ Ready for Review filter — these 467 bundles have all stock in Germany and are your immediate opportunity.
  • Step 2: Export CSV using the ↓ Export CSV button and share with the listings team.
  • Step 3: For the Missing Components group — check which missing SKUs appear most frequently across many bundles. Sourcing one key SKU may unlock dozens of bundles.
  • Step 4: Search a specific SKU (e.g. CRSF100BM) to see all bundles containing it.

Data & Refresh

Data is pulled live from the database and auto-refreshes every 5 seconds. Numbers update automatically as listings are added or stock changes. The refresh date in the source bar shows the last successful data pull.

Important: This report shows opportunity only — it does not calculate how many units of a bundle can be built, and it does not recommend or trigger any listing creation.
