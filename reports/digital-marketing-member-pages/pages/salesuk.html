Why this page exists: the main sales dashboard's per-staff tabs (Kamsi/Dilaksi/DM/Sonya/Sajeepan) can double-count the same order under different definitions (product-scope vs ad-click attribution). This standalone page shows every order once, at order level, so it can be reviewed and assigned by hand. Groups on this page are checked in a fixed priority order (DM-Ad, then Meta) so no order can ever appear in more than one group's tab here.
Matching rule: first-session utm_campaign exactly matches (or is a prefixed variant of) Shop_DM_PMax-46_AguAsset or Shop_DM_PMax-25 (case-insensitive). Sessions 2+ are never used for matching, only shown for context.
Scope: store-wide, not product-scoped — order-level rows only, no per-product/SKU breakdown.
Report period: January 1–31, 2026, Europe/London timezone.
Privacy: no customer email, phone, address, or payment data is fetched, stored, or displayed.
