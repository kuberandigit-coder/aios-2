ℹ️ Features Not Supported — Data Not in DB
❌ Merchant Centre Disapprovals — GMC Content API not connected. No eligibility/approval/policy columns exist on merchant_products. Check Google Merchant Center UI directly.
❌ GTIN Duplicate Detection — No GTIN/barcode/EAN field in any table (confirmed missing from both Postgres and MySQL source).
❌ Feed Staleness / Last Updated — merchant_products has no updated_at timestamp. Rows are upserted each sync with no change history.
❌ Numeric Shopify Stock — No working join from Google product IDs to Shopify variant stock quantity. Availability shown as In Stock / Out of Stock from Merchant feed only.
❌ Duplicate Variant Attributes — selected_variations stored as JSONB with no structured colour/size columns — cross-variant comparison not possible.
